# LifeDesk — AI-Powered Productivity Platform

LifeDesk is a productivity platform designed to help users organize tasks, plan their day, and manage calendar events in one place. It combines structured task management with AI-assisted productivity features and Google Calendar integration.

## Features

### Task Management
- Create and organize tasks.
- Set task priorities and deadlines.
- Track estimated duration and task difficulty.
- Categorize tasks and specify energy requirements.
- Review productivity insights through the dashboard.

### AI-Assisted Productivity
- AI assistance to support task planning and daily productivity.
- Designed to help users organize work and manage tasks more effectively.

### Google Calendar Integration
- Connect a Google account through OAuth 2.0.
- Check whether Google Calendar is connected.
- Create calendar events from the dashboard.
- Specify an event title, description, start time, and end time.
